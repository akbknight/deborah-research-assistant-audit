#### In-Depth Narrative (Expanded Case Study / Modal View):
> Bridging enterprise software engineering and rigorous forensic data science, this project documents a complete technical post-mortem of the **Deborah Research Assistant** codebase across 17 release-lineage milestones. By reverse-engineering cryptographic manifests, execution traces, and AST diffs across 62 legacy archives, I reconstructed a 44-finding security and platform defect ledger—identifying critical time-of-check to time-of-use DNS-rebinding SSRF vulnerabilities, cross-platform NTFS file-descriptor collisions, and upstream Cloudflare WAF bot-mitigation barriers. 
>
> Moving beyond passive code review, I built a continuous DataOps telemetry pipeline using Python (`pandas`, `matplotlib`), Mermaid.js, and GitHub Actions to dynamically visualize test suite expansion (growing from 67 static assertions to 4,426 automated tests) alongside the empirical stability gap between Linux production and Windows environments. The resulting open-source repository serves as an industry-standard template for technical debt auditing, architectural accountability, and extracting actionable business intelligence from legacy systems.
